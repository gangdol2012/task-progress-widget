The widget is open in the top-right corner of your main screen.

Claude loads the widget's mod when it starts. If Claude was open, a window asked whether to restart it now. If you chose Later, fully quit Claude and open it again when it suits you (Claude menu > Quit Claude, or Command-Q; closing the window isn't enough). Sessions show up in the widget after that. Claude Code sessions you start in a terminal show up on their own.

Click a line to open that session, drag the widget to move it, and right-click it for settings.

To uninstall, run this in Terminal:
bash "/Applications/Claude Progress.app/Contents/Resources/uninstall.command"
